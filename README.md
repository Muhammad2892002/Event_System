# Event Management System

A full-stack web application for managing events, allowing users to create, book, and manage events with role-based access (Admin/User).

## Technologies Used
- **Backend:** ASP.NET Core (.NET 8), Web API, Entity Framework Core, JWT Authentication
- **Frontend:** Angular, Components, Services, Guards, Interceptors, Reactive Forms
- **Database:** SQL Server
- **Tools:** Visual Studio, SSMS, Git/GitHub

## How to Run
1. Open the **Backend** project in Visual Studio.
2. Ensure SQL Server database is configured.
3. Run the Backend (Web API).
4. Open the **Frontend** project in Visual Studio Code or any Angular IDE.
5. Run Angular app (`ng serve`) to access the interface.

## Key Features
- **Authentication & Role-Based Access:** Users log in with roles (Admin/User) using JWT.
- **Event Management:** Create, update, delete, and view events.
- **Interactive User Interface:** Dynamic pages using Angular Components and Reactive Forms.
- **Full Frontend-Backend Integration:** Using Angular HTTPClient and RESTful APIs.
- **Clean, Scalable Architecture:** Layered architecture and Dependency Injection for maintainable code.
